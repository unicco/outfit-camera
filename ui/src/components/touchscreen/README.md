# タッチスクリーン UI

## 概要

玄関に設置する5インチタッチスクリーン（800x480px）専用のUIです。

## アクセス方法

### 開発環境

```bash
# フロントエンドサーバーを起動
npm run dev

# ブラウザでアクセス
http://localhost:5173/touchscreen
```

### 本番環境（Raspberry Pi）

```bash
# Raspberry Pi上でアクセス
http://pi-camera.local:3000/touchscreen
```

## 機能

### 1. 人物検知による自動起動

- カメラが人を検知すると自動的にディスプレイがONになります
- WebSocket経由でカメラサービスと連携

### 2. 画面遷移

1. **スタンバイ画面**: 撮影ボタンを表示
2. **カウントダウン画面**: 3秒のカウントダウン（キャンセル可能）
3. **プレビュー画面**: 撮影した写真の確認
4. **完了画面**: 記録完了メッセージ（3秒後に自動でスタンバイへ）

### 3. 自動タイムアウト

- 30秒間操作がないとディスプレイが自動的にOFFになります
- 人物検知またはタッチでディスプレイが再度ONになります

## 環境変数

```bash
# API エンドポイント
VITE_API_URL=http://localhost:8000

# カメラサービスエンドポイント
VITE_CAMERA_URL=http://localhost:8001
```

## タッチ操作の最適化

- すべてのボタンに `touchAction: 'manipulation'` を設定してダブルタップズームを防止
- タッチイベントの即時反応のためのカスタムフック実装
- 視覚的フィードバック（ボタンの押下効果）

## WebSocket通信

カメラサービスとの通信プロトコル：

- `person_detected`: 人物を検知
- `person_lost`: 人物がいなくなった
- `display_on`: ディスプレイをONにする
- `display_off`: ディスプレイをOFFにする
- `capture_complete`: 撮影完了
